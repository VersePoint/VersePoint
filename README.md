VersePoint


A clean and focused Scripture & lyrics projection app for churches, built for clarity and simplicity.

✨ Features


▸ Scripture Mode
Clear Bible verse projection

High-contrast layout for large screens

Simple navigation between passages

Distraction-free presentation



▸ Lyrics Mode
Worship song lyric projection

Consistent formatting and readability

Designed for congregation visibility

🎯 Purpose


VersePoint exists to help churches present Scripture and worship lyrics clearly and reverently during services, sermons, and gatherings.



The design prioritizes:

Clarity

Simplicity

Stability

Ease of use for volunteers
