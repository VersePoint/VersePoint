# VersePoint — Free Church Presentation Software

Present **Bible verses and song lyrics**, plan your church service, and send Web Output to OBS for livestreaming. VersePoint is a desktop app for **Windows and macOS**, free to use for churches and other non-commercial purposes under its [license](LICENSE).

## Built for the worship team

- **Scripture and lyrics:** Find Bible verses, arrange song slides, and control what appears live.
- **Service planning:** Organize Scripture, songs, media and documents with Programs and Service Flow.
- **Presentation design:** Use motion backgrounds, typography presets and Overlay Graphics such as lower thirds, announcements, QR codes and countdowns.
- **Projector and livestream output:** Present to a connected screen and add Web Output as an OBS browser source. Web Output has its own presentation settings.
- **Mobile requests and control:** Receive Scripture and song requests from phones on the same local network. The operator approves live control.
- **Documents:** Present supported PDF, PowerPoint and Keynote documents as static slides. Formats other than PDF require an installed converter; see the release notes.
