VersePoint is a free Electron-based presentation app built for church services and live streaming, available for both Windows and macOS. It helps teams quickly project Bible verses and song lyrics with clean visuals, consistent screen parity, and fast live control.

Key capabilities include Scripture and Lyrics workflows, Program organization, customizable styling/themes, media and dynamic backgrounds, and Web Out output for OBS/browser-source setups across a network. VersePoint is designed for practical live use: simple operation, flexible styling, and reliable output to Preview, Projector, and Web Out.
